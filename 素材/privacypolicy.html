星辰云巡隐私政策

更新日期：2026年08月25日

生效日期：2026年08月25日

星辰云巡是由衣峻辰（以下简称“我们”）开发并运营的服务器监控客户端。本政策用于说明星辰云巡在您使用应用期间如何处理信息，以及您如何管理相关信息和设备权限。

特别提示：星辰云巡本身不为您托管监控数据，也不要求注册应用账户。应用会按照您的配置连接您指定的监控服务器。服务器的运营者、数据处理规则和安全能力由您或相关第三方负责，请您在绑定前确认对该服务器及 API Token 具有合法授权。

1. 我们如何收集和使用信息

1.1 服务器绑定信息

当您手动输入或通过二维码绑定监控服务器时，应用会处理以下信息：

  • 服务器地址：用于确定监控 API 的请求目标。
  • API Token：用于通过 Bearer Token 方式向您指定的服务器进行身份验证。
  • Token 权限范围（如二维码中包含）：用于判断应用是否可以执行告警确认等操作。

上述绑定信息保存在您的设备本地，用于在后续启动时恢复连接。我们不会将绑定信息主动上传至由我们运营的服务器。

1.2 监控数据

连接成功后，应用会从您指定的服务器读取、展示并在应用运行期间处理监控数据，可能包括：

  • 设备名称、主机名、操作系统、架构、IP 地址、位置、分组、在线状态和硬件信息；
  • CPU、内存、交换空间、负载、磁盘、网络流量、连接数等运行指标；
  • 磁盘挂载信息、进程名称、进程所属用户名、进程状态和系统服务状态；
  • HTTP、Ping、TCPing 等网络服务的名称、目标地址、可用性、延迟、状态码及证书到期时间；
  • 告警规则、告警内容、严重级别、处理状态、发生时间、确认人员等告警信息。

这些数据用于提供概览、设备详情、服务可用性、历史趋势和告警查看功能。应用也可根据您的操作向目标服务器发起“立即检查服务”或“确认告警”请求。

部分监控数据可能包含个人信息、内部网络信息或商业敏感信息。请确保您有权查看和处理这些数据，并为 API Token 配置满足实际用途的最小权限。

1.3 应用设置

应用会在设备本地保存自动刷新开关、刷新间隔、是否显示完整 Token、主题颜色和颜色模式等设置，以保持您的使用偏好。

1.4 剪贴板

仅当您主动点击“复制 Token”时，应用才会将当前 API Token 写入系统剪贴板。应用不会为该功能读取剪贴板内容。剪贴板内容可能被系统或其他具备相应能力的应用访问，请您复制后妥善保管，并避免在不受信任的应用中粘贴。

3. 信息传输、存储与安全

3.1 传输对象

服务器地址、API Token 和监控请求会直接发送至您指定的服务器。服务器可能由您本人、您的组织或第三方服务商运营，我们不控制该服务器如何记录、保存或进一步处理请求信息。请您查阅该服务器运营者的隐私规则和安全说明。

3.2 传输安全

应用支持您配置 HTTP 或 HTTPS 地址。我们强烈建议始终使用可信的 HTTPS 地址。如果您选择 HTTP，API Token 和监控数据可能在传输过程中面临被监听、篡改或泄露的风险，由此产生的风险需由您自行评估和承担。

3.3 本地存储与期限

服务器地址、API Token、Token 权限范围和应用设置会保存在设备本地，直至您解除绑定、清除应用数据或卸载应用。应用从服务器获取的监控数据主要用于当前运行期间展示，不作为由我们运营的云端数据进行保存。

3.4 系统备份与恢复

应用支持 HarmonyOS 系统提供的备份与恢复能力。根据您的设备和系统备份设置，本地应用数据可能由系统备份服务进行备份，并在换机、重装或恢复设备时还原，其中可能包含服务器地址、API Token 和应用设置。相关备份由系统服务按照其隐私规则处理。您可以通过设备的备份设置管理相关功能。

3.5 安全建议

  • 使用只读或最小权限 Token，仅在确有需要时授予告警写入等权限；
  • 使用 HTTPS，并确认服务器证书和域名可信；
  • 不要与他人共享 Token，不要在公共设备上长期保存 Token；
  • 怀疑 Token 泄露时，请立即在服务器端撤销并重新生成；
  • 使用设备锁屏、系统加密和最新安全更新保护本地数据。

4. 信息共享、转让与公开披露

我们不会出售您的个人信息。除以下情形外，我们不会向第三方共享、转让或公开披露由应用处理的信息：

  • 根据您的主动选择，将请求发送至您指定的监控服务器；
  • 使用 HarmonyOS 提供的相机授权、图片选择、二维码识别、剪贴板、备份与恢复等系统能力完成您请求的功能；
  • 根据法律法规、诉讼争议解决需要，或行政、司法机关依法提出的要求进行必要处理；
  • 为保护您、我们或其他人的生命、财产等重大合法权益，在法律允许范围内进行必要处理。

当前版本未集成广告、用户行为分析或由我们运营的云端账号系统。

5. 您如何管理信息与权限

  • 查看或修改绑定信息：可在应用“设置”中查看服务器信息并重新绑定。
  • 删除绑定信息：可在应用“设置”中选择“解除绑定”，清除本地保存的服务器地址、API Token 和 Token 权限范围。
  • 删除全部本地数据：可通过系统应用设置清除星辰云巡的数据，或卸载应用。
  • 管理相机权限：可在系统设置的应用权限页面随时授权或撤回。
  • 删除服务器端数据：星辰云巡不直接控制您指定服务器中的数据。您应使用目标服务器提供的管理功能，或联系其运营者处理。

请注意，系统备份中已有的数据可能在恢复后重新出现。您可同时检查并管理设备的系统备份设置。

6. 未成年人保护

星辰云巡是面向服务器管理与运维场景的工具，不以未成年人为目标用户。未满十四周岁的未成年人不应自行配置服务器凭据或使用本应用；确有使用需要的，应在监护人同意和指导下进行。若监护人发现未成年人未经同意处理了相关信息，可通过本政策载明的方式联系我们。

7. 本政策的更新

我们可能因功能变化、法律法规要求或安全需要更新本政策。对于对您权益有重大影响的变更，我们会通过应用内提示、版本说明或其他适当方式向您说明。更新后的政策自标明的生效日期起施行；若您不同意更新内容，请停止使用相关功能并删除本地数据。
