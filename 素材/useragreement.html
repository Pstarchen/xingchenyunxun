1. 服务主体与协议范围

星辰云巡是由衣峻辰开发并运营的服务器监控客户端。本协议适用于星辰云巡当前及后续版本提供的客户端功能。应用内展示的操作说明、安全提示、版本说明以及《星辰云巡隐私政策》均为本协议不可分割的组成部分。

若您代表组织使用本应用，您确认已获得该组织的有效授权，并有权代表该组织接受本协议及承担相应责任。

2. 服务内容与性质

星辰云巡可帮助您连接有权访问的监控服务器，并提供包括但不限于以下功能：

  • 通过服务器地址和 API Token 手动绑定监控服务器；
  • 通过相机或二维码图片识别绑定信息；
  • 查看设备状态、系统资源指标、磁盘、进程、服务和网络流量等监控数据；
  • 查看 HTTP、Ping、TCPing 等服务的可用性、延迟、历史结果和证书状态；
  • 查看告警，并在 Token 权限允许时确认告警；
  • 主动触发服务检查、自动刷新数据、切换主题和管理本地连接设置。

星辰云巡是客户端工具，不是监控服务器、云托管服务或网络运营服务。应用不会为您创建监控账户，也不负责存储、采集或维护目标服务器中的原始监控数据。实际可用功能取决于您指定服务器的版本、接口、运行状态和 API Token 权限。

3. 使用资格与授权要求

您应当具备与使用本服务相适应的民事行为能力。若您不具备完全民事行为能力，应在监护人的同意和指导下阅读并接受本协议。

您只能连接由您合法拥有、管理，或已获得所有者明确授权访问的服务器、设备和监控系统。您应确保 API Token 来源合法、权限范围适当，并有权查看和处理服务器返回的设备信息、IP 地址、进程、用户名、位置、告警和其他数据。

如您处理的信息涉及个人信息、商业秘密、关键信息基础设施或其他受保护数据，您应自行确保具备合法处理基础，并履行适用法律法规要求的告知、授权、安全保护和审计义务。

4. API Token 与设备安全

API Token 是访问监控服务器的重要凭据。您应对 Token 的生成、权限配置、保管、使用、更新和撤销负责。

  • 优先使用只读或满足实际用途的最小权限 Token；
  • 不要将 Token 提供给无关人员，不要在公共设备上长期保存；
  • 不要通过不可信的二维码、消息、网页或应用导入绑定信息；
  • 不要在不受信任的应用中粘贴已复制到剪贴板的 Token；
  • 怀疑 Token 泄露、设备丢失或权限异常时，应立即在服务器端撤销 Token；
  • 解除绑定只会清除本机保存的连接信息，不会自动撤销服务器端 Token。

安全提示：请使用可信 HTTPS 地址。若您自行配置 HTTP 地址，Token 和监控数据可能以缺乏充分传输保护的方式发送，由此产生的监听、篡改、冒用或泄露风险由您自行承担。

  • 绕过服务器权限控制、身份验证、安全策略、访问频率限制或审计机制；
